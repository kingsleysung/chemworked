How to balance a chemical equation

Atoms can't be created or destroyed, so every element needs the same number of atoms on both sides. You balance by changing coefficients (the big numbers in front), never the subscripts.

  1. Write the correct formula for every reactant and product.
  2. Count the atoms of each element on both sides.
  3. Balance elements that appear in only one compound per side first. Leave H and O (and pure elements like O₂) for last.
  4. Adjust coefficients until every element matches, then reduce to the smallest whole numbers.

Worked example: rusting iron

Fe + O₂ → Fe₂O₃. Oxygen is 2 on the left and 3 on the right, so the lowest common multiple is 6: use 3 O₂ and 2 Fe₂O₃. That makes 4 Fe on the right, so use 4 Fe on the left.
4 Fe + 3 O₂ → 2 Fe₂O₃

Tip for combustion reactions

For CxHy + O₂ → CO₂ + H₂O: balance C first (CO₂), then H (H₂O), then O last. If you get a fraction like 13/2 O₂, multiply everything by 2.

This tool balances by atoms only. It doesn't check whether the reaction actually happens or balance ionic charges.
