Significant figures calculator

Count sig figs, round a number, or do math with the right sig fig rules. Every answer explains which rule was used.

Scientific notation works: 1.20e3 or 1.20x10^3.

Rules for counting significant figures

  1. Non-zero digits are always significant. 4.56 has 3.
  2. Zeros between non-zero digits are significant. 1005 has 4.
  3. Leading zeros are never significant. They only place the decimal point: 0.0045 has 2.
  4. Trailing zeros after a decimal point are significant. 2.500 has 4.
  5. Trailing zeros in a whole number with no decimal point are ambiguous. 1200 could have 2, 3 or 4. Write 1.20 × 10³ (3 sig figs) or 1200. (4 sig figs) to be clear.

Sig fig rules for calculations

Multiplying and dividing

The answer has the same number of significant figures as the value with the fewest. Example: 4.56 ÷ 1.4 = 3.257… → 3.3 (1.4 has only 2 sig figs).

Adding and subtracting

The answer has the same number of decimal places as the value with the fewest. Example: 12.11 + 18.0 = 30.11 → 30.1 (18.0 only goes to the tenths place).

Multi-step problems

Keep extra digits in the middle steps and round only the final answer. Rounding at every step adds error.

Exact numbers

Counted numbers (3 beakers) and defined conversions (1000 mL = 1 L) have unlimited sig figs. They never limit your answer.
